# pinpong
## 1. 作業介紹
本專案使用 VHDL 在 ZedBoard FPGA 上實作 Ping-Pong LED 遊戲，利用 8 顆 LED 模擬球的移動，並透過左右按鈕進行操作。

## 2. 系統功能
- LED 球從左側開始向右移動，抵達右側後等待玩家按下右側按鈕。
- 成功按下按鈕後，LED 球向左移動，抵達左側後等待玩家按下左側按鈕。
- 若按錯按鈕或超過等待時間，則判定失敗並由對方得分。
- 遊戲結束時顯示雙方分數，並可透過按鈕重新開始遊戲。
- 使用按鈕同步及除彈跳機制，避免按鈕訊號造成誤判。

## 3. 程式檔案
- `pingpong_board.vhd`：控制 LED 移動、按鈕判斷、遊戲狀態及分數。
- `pingpong_tb.vhd`：模擬遊戲操作，測試 LED 移動及按鈕判斷。
- `XDC file`：設定 FPGA 腳位及輸入輸出訊號。

## 4. 狀態機
本遊戲使用有限狀態機（FSM）控制 LED 移動、按鈕判斷及遊戲流程，共有五個狀態：

- `MOVE_RIGHT`：控制 LED 球向右移動。
- `WAIT_RIGHT`：LED 球抵達右側，等待玩家按下右側按鈕。
- `MOVE_LEFT`：控制 LED 球向左移動。
- `WAIT_LEFT`：LED 球抵達左側，等待玩家按下左側按鈕。
- `ROUND_OVER`：遊戲結束，顯示雙方分數並等待重新開始。

## 5. 遊戲結果
透過 8 顆 LED 模擬球的左右移動，玩家需在球抵達邊界時按下正確按鈕，成功則將球擊回對方。若操作失敗，對方得分，並於遊戲結束時顯示雙方分數。
