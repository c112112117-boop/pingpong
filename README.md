# pinpong
LED 乒乓球遊戲，使用兩顆按鈕與八顆 LED，透過左右按鈕控制乒乓球的移動方向，利用 LED 依序亮起，模擬乒乓球來回移動的效果。

遊戲開始時，LED 從最左邊開始往右移動，當 LED 到達最右邊時，等待右方玩家按下按鈕（sw_r）回擊；成功回擊後，LED 會往左移動。當 LED 到達最左邊時，則等待左方玩家按下按鈕（sw_l）回擊，成功後再往右移動。

如果玩家沒有及時按下按鈕，或按錯按鈕，則由對方得分。回合結束後，LED 會顯示雙方分數，按下任一按鈕即可重新開始下一回合。

狀態機共有 5 種狀態：

S0（MOVE_RIGHT）：LED 往右移動。

S1（WAIT_RIGHT）：LED 到達最右邊，等待右方玩家回擊。

S2（MOVE_LEFT）：LED 往左移動。

S3（WAIT_LEFT）：LED 到達最左邊，等待左方玩家回擊。

S4（ROUND_OVER）：回合結束，顯示雙方分數，等待玩家按下按鈕重新開始。

時脈設定：

使用 100MHz 系統時脈，透過計數器產生 LED 移動的時間控制，每隔 0.75 秒移動一格 LED，並使用 Clock Enable 控制移動，不另外產生新的時脈。

按鈕消抖：

加入按鈕同步與消抖功能，避免按鈕按下時產生訊號跳動，造成一次按下被誤判成多次觸發，並透過單次觸發訊號判斷玩家是否按下按鈕。

計分功能：

使用 left_score 與 right_score 分別記錄左右玩家的分數。當玩家回擊失敗或按錯按鈕時，由對方增加一分。回合結束後，利用八顆 LED 顯示雙方分數，並可按下按鈕重新開始遊戲。
